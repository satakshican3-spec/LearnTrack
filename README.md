# LearnTrack 8-12
**A data-driven study tracking and grade prediction app for Canadian students.**

LearnTrack is a free app designed to help students master their academic goals. Built with Python and Streamlit, it features a focus timer and a grade predictor to help students on their journey to top-tier universities.

## Features
- Focus Timer: Maximize study efficiency.
- Grade Predictor: Calculate needed scores for finals.
- Progress Tracking: Monitor study minutes for all subjects.

## Tech Stack
- Language: Python
- Framework: Streamlit
